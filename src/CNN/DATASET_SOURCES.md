# Dataset source and use

The local data was downloaded from the Hugging Face dataset repository
[`printblue/EmoArt-5k`](https://huggingface.co/datasets/printblue/EmoArt-5k),
revision `main`, on 2026-10-28. The repository supplied `Images.tar.gz` and
`annotation.json` (5,532 annotation records; 5,532 image paths resolved).

The Hugging Face README displays a Creative Commons badge and describes the
artworks as open-access/public-domain, but this repository snapshot contains no
`LICENSE` file or exact license identifier. Some other descriptions identify
CC BY-NC 4.0. Confirm the applicable terms with the authors before
redistributing. License metadata is not a substitute for per-image
provenance: image files may have individual museum/source conditions. See the
project-root `EMOART_DATA_LICENSE.md`; the project's MIT license applies only
to its code.
